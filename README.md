# mu-rising-updates

Arquivos públicos de atualização do Mu Rising:

- `manifest.json`: manifesto dos plugins nativos do servidor.
- `streamers.json`: IDs Discord e canais públicos dos streamers parceiros usados pelo bot Mu Rising Live.

Tokens do Discord e credenciais das plataformas ficam somente no arquivo `.env` local do bot. Não publique segredos neste repositório.
